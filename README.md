##  Sobre a Aplicação

### Objetivo
Criar um portfólio coletivo onde cada membro do grupo compartilha um lugar que gostaria de visitar, explicando as razões e curiosidades sobre o destino escolhido.

##  Pré-requisitos

Para executar este projeto, você precisa de:

- **Navegador Web Moderno** - Qualquer navegador recente:
- **Git** (v2.0+) - Para clonar e contribuir com o repositório
- Navegador com suporte a HTML5 CSS3 

##  Como Executar

1. **Clonar o repositório** (se necessário):
   ```bash
   git clone https://github.com/FelipeKogake/PR-configuracoes-treino-hands-on.git
   cd PR-configuracoes-treino-hands-on
   ```

2. **Abrir no navegador**:
   - Abra `index.html` em seu navegador preferido
   - Navegue pelos links para visualizar cada página individual

3. **Editar/Personalizar**:
   - Modifique os arquivos HTML em `html/`
   - Customize os estilos em `css/`
   - Atualize os assets em `assets/`

## Estrutura do Projeto

O projeto é composto por:
- **1 página principal** (`index.html`) - Hub central com links para todos os membros
- **5 páginas individuais** - Uma para cada integrante do grupo:
  - Felipe Kogake - Londres
  - João Prado - Suíça
  - Lucas Lima - Japão
  - Maria Eduarda Rosa - Suiça
  - Tainá Martinelli - Itália

### Funcionalidades

 **Página Principal (index.html)**
- Menu de navegação com links para todas as páginas individuais
- Design moderno com efeito glassmorphism
- Footer com informações do projeto
- Estilização responsiva e atraente

 **Páginas Individuais**
- Seção "Sobre o aluno" com nome e turma
- Descrição do lugar escolhido e motivos da escolha
- Curiosidades e fatos interessantes sobre o destino
- Botão de retorno à página principal
- Estilo visual único para cada membro (CSS personalizado)
